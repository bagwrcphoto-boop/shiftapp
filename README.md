# เวรของฉัน (shiftapp)

แอปตารางเวรพยาบาล + วิดเจ็ต สำหรับแอป [Scriptable](https://scriptable.app) บน iPhone

- อัปรูปตารางเวร → AI (Gemini ฟรี / Claude) อ่านเวรทุกคนในวอร์ด
- ปฏิทิน · สรุปเดือน · เวรเพื่อน · ธีม 5 สไตล์ × 6 สี
- วิดเจ็ตเล็ก/กลาง/ใหญ่/หน้าจอล็อก · ใส่ปฏิทิน iPhone · แจ้งเตือนก่อนขึ้นเวร

## ติดตั้ง
1. สร้างสคริปต์ใหม่ใน Scriptable ชื่อ `ShiftApp`
2. วางโค้ดจาก [`loader.js`](loader.js) แล้วใส่ชื่อกับ Gemini key ในส่วน `CONFIG`
3. กดรัน — แอปจะโหลด `app.js` เวอร์ชันล่าสุดจาก repo นี้เอง

ไม่มี key หรือข้อมูลเวรอยู่ใน repo นี้ ข้อมูลทั้งหมดเก็บในเครื่อง

## พัฒนา
แก้ไฟล์ใน `src/` แล้วรัน `python3 build.py` เพื่อสร้าง `app.js` และ `preview.html`
